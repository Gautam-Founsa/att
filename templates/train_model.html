What is Training?

Training processes all captured face images and creates a face recognition model. This model learns to identify students based on their facial features.

Training Steps:
  1. Load all face images from dataset
  2. Extract facial features (encodings)
  3. Create recognition model
  4. Save model for future use
Duration

Training time depends on the number of images:

  • 10-20 images: ~30 seconds
  • 50-100 images: ~1-2 minutes
  • 200+ images: ~5 minutes
